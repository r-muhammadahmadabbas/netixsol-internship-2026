Here's where you can get the UCI Adult (Census Income) dataset:

Easiest option — directly in code:

python
from sklearn.datasets import fetch_openml
adult = fetch_openml('adult', version=2, as_frame=True)
df = adult.frame
This pulls it straight from OpenML (mirrors the UCI dataset) with no manual download needed — sklearn caches it locally after the first fetch.

Direct sources if you want the raw files:

UCI ML Repository (original source): https://archive.ics.uci.edu/dataset/2/adult — gives you adult.data, adult.test, and adult.names (column descriptions)
OpenML page (what sklearn pulls from): https://www.openml.org/d/1590
Kaggle mirror (if you prefer a CSV with headers already set): search "Adult Census Income" on Kaggle — commonly adult.csv
A couple of practical notes for Task 2 in your assignment:

The raw UCI files use " ?" (with a leading space) for missing values, not just "?" — so when cleaning, use df.replace(' ?', np.nan) or strip whitespace first, or you'll miss them.
The raw adult.test file has a trailing period after the target labels (e.g., >50K. vs >50K) — a classic gotcha that breaks label matching if you concatenate train and test naively. Using fetch_openml avoids this since it's already cleaned.
Column names aren't in the raw data files — they're in adult.names. fetch_openml(as_frame=True) gives you proper column names automatically.

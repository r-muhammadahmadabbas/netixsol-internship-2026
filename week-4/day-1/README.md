# Week 4 Day 1 — Foundations of AI Voice Agents & Conversation Design

## Overview
Design the foundational architecture, conversation flows, and persona for a production-ready real estate AI voice agent.

## Tasks
1. **Research Voice Agent Architecture** — Document STT, LLM, TTS, telephony, workflow orchestration
2. **Design Conversation Flows** — 7 flowcharts for different inquiry types
3. **UrduLish Persona Engineering** — Design Pakistani real estate salesperson personality
4. **Fish Audio Evaluation** — Compare against ElevenLabs across 9 criteria
5. **System Prompt Design** — Production-grade prompt with scope, guardrails, policies

## Deliverables
- Architecture diagram
- 7 conversation flowcharts
- UrduLish persona document
- Fish Audio evaluation report
- System prompt

## How to Run
```bash
# View diagrams and documents
ls day-1/
```

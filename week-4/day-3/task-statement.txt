Week 4 — Day 3: Voice Agent & Natural Conversation

📌 Scenario: Today's goal is to make the agent sound indistinguishable from a real Pakistani sales executive.

Task 1 — Streaming Voice Pipeline
Implement Speech → LLM → Voice. Keep latency under 2 seconds.

Task 2 — Natural Speech Behaviors
Implement:
- Interruptions
- Fillers
- Hesitation
- Thinking pauses
- Laughter
- Acknowledgements
Examples: "Hmm...", "Ji bilkul...", "Ek second sir...", "Acha..."

Task 3 — Context Memory
Support conversations like:
Client: "Budget 3 crore hai."
Later: "DHA mein kya options hain?"
Later: "Us se sasti koi option?"
Memory should work naturally.

Task 4 — Objection Handling
Train the agent to answer:
- Price concerns
- Trust issues
- Location concerns
- Investment concerns
- Builder concerns
- Maintenance

Task 5 — Human Evaluation
Record conversations. Score:
- Naturalness
- Persuasiveness
- Fluency
- Latency
- Conversation flow

# Week 4 Day 3 — Voice Agent & Natural Conversation

## Overview
Make the agent sound indistinguishable from a real Pakistani sales executive.

## Tasks
1. **Streaming Voice Pipeline** — Speech → LLM → Voice, latency < 2s
2. **Natural Speech Behaviors** — Interruptions, fillers, hesitation, pauses, laughter
3. **Context Memory** — Multi-turn conversations with natural reference resolution
4. **Objection Handling** — Price, trust, location, investment, builder, maintenance
5. **Human Evaluation** — Record and score conversations on 5 metrics

## Deliverables
- Streaming voice pipeline
- Natural speech behavior implementation
- Context memory system
- Objection handling library
- Human evaluation report

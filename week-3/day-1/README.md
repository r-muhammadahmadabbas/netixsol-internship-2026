# Week 3 Day 1 — AFL Data Foundations: EDA, Feature Engineering & Prediction Targets

## Dataset
- **Source:** Google Drive AFL Dataset
- **Files:**
  - `afl_players_info_raw.csv` — Player demographics (650KB)
  - `afl_players_round_by_round_stats_raw.csv` — Player round-by-round stats (40MB)
  - `afl_players_seasonal_stats_raw.csv` — Player seasonal aggregated stats (5MB)
  - `team_matches_home_away_raw.csv` — Match results with home/away (2.2MB)

## Tasks
1. **Data Inventory & Understanding** — Load, document, check quality
2. **Define Prediction Targets** — Match winner, top player metrics
3. **Exploratory Data Analysis** — Win rates, distributions, visualizations
4. **Feature Engineering** — Rolling features, head-to-head, context
5. **Reproducible Train/Hold-Out Split** — Time-based split

## How to Run
```bash
jupyter notebook
```
Open the notebook and run all cells.

## Deliverables
- Clean Jupyter notebook with EDA + feature engineering
